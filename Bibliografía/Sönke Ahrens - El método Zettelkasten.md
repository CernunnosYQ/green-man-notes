# El método Zettelkasten

El método Zettelkasten es un sistema de toma de notas diseñado para mejorar la creatividad y el aprendizaje continuo mediante la interconexión de ideas, funcionando como un "segundo cerebro".
Se basa en notas individuales que se vinculan entre ellas mediante enlaces, sin categorizarse, creando así una red horizontal de pensamiento, imitando la forma en que funciona el cerebro humano.
